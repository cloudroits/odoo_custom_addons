Website Popup Image - Odoo Module


Module Overview

This Odoo module allows you to display customizable image popups on selected pages of your website. The popup can include an image, a button with custom text, and a link. You can choose which pages the popup should be displayed on, as well as which websites if you're managing multiple sites within Odoo.


Features

  • Display image popups on selected pages of your website.
  • Customizable button text and link within the popup.
  • Choose which websites and pages the popup should appear on.
  • Easy configuration through the Odoo backend.
  • Responsive design ensures the popup looks great on all devices.

How to Use the App

Follow these steps to configure and use the Website Popup Image module:

  1. Navigate to the Odoo backend and go to Website > Configuration > Popup Images.
  2. Click on Create to add a new popup configuration.
  3. Fill in the following fields:
    • Name: Enter a name for the popup configuration.
    • Popup Image: Upload the image that will be displayed in the popup.
    • Websites: Select the websites where the popup should appear.
    • Button Text: (Optional) Enter the text that will be displayed on the button inside the popup.
    • Button Link: (Optional) Provide a URL where users will be directed when they click the button.
    • Page URLs: Specify the URLs where the popup should be displayed. Separate multiple URLs with commas. Leave this field empty to show the popup on all pages of the selected website(s).
  4. Example values for Page URLs:
    • To display the popup on the home page: /
    • To display the popup on a specific page like the shop page: /shop
    • To display the popup on multiple pages: /, /shop, /contactus
  5. Save your configuration.
  6. Visit the specified pages on your website to ensure the popup appears as expected.

Note: Ensure that the JavaScript and CSS files are correctly loaded on your website to display the popup correctly.


User Access Configuration

To allow a specific user to manage the popup settings, follow these steps:

  1. Navigate to the Odoo backend and go to Settings > Users & Companies > Users.
  2. Select the user you want to grant access to.
  3. Under the Access Rights tab, assign the user to the Popup Image Manager group found under Website Popup Settings.
  4. Ensure the user has the necessary permissions to manage the Website to Website and configuration settings, such as Website Editor or Website Manager.
  5. Save the user configuration.

With these settings, the user will be able to access and manage the popup configurations as needed.
